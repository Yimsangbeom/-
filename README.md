# OMR 카드 자동 채점 (ocr.ehancom.com)

## 서버(D:\OCR_Score)에서 실행
1. 이 저장소 파일을 `D:\OCR_Score`에 덮어쓰기
2. `run.bat` 실행 (venv 생성 → 패키지 설치 → waitress로 80포트 서비스)
3. 브라우저에서 `http://localhost` 확인 후 `http://ocr.ehancom.com`

## 아이디 / 비밀번호
- **최초 설정**: 서버 PC 브라우저에서 `http://127.0.0.1:5000` 접속 → 아이디(기본 `hancom`)와 비밀번호 입력. (외부 접속으로는 설정 불가 → 남이 먼저 선점할 수 없음)
- **변경**: 로그인 후 화면 오른쪽 위 [아이디/비밀번호 변경] (현재 비밀번호 필요, 변경 시 다른 기기는 로그아웃)
- **잊어버렸을 때**: 서버에서 `reset_password.bat` 실행(= `data\auth.json` 삭제, 채점 결과/정답은 유지) → 위 최초 설정 다시
- 5회 연속 실패 시 해당 IP 5분 잠금, 로그인 12시간 유지. 비밀번호는 해시로만 저장.

## 자동 시작 (재부팅 후에도)
아래 "항상 켜져 있게" 절의 `install_service.ps1` 을 사용합니다. (예전 `schtasks /create ... start_server.bat` 방식은 72시간 제한/자동 재시작 없음 문제가 있어 대체됨)

## 배점 / 합격 / 과락 판정
- 5과목 x 20문항, **문항당 5점 -> 과목 만점 100점, 총점 만점 500점** (홈 화면에서 변경 가능)
- **과락**: 한 과목이라도 과락 점수(기본 40점) **미만**이면 과락 (평균이 높아도 불합격). 0 이면 사용 안 함
- **합격**: 과락이 없고 **평균(총점/5)이 합격 평균(기본 60점) 이상**. 미달이면 불합격
- 설정(문항당 배점/합격 평균/과락 점수)을 바꾸면 이미 채점된 결과도 즉시 다시 계산/판정 (엑셀에 과목별 점수, 총점, 평균, 판정, 과락과목 포함)
- 이전 버전 설정이 남아 있으면 처음 시작할 때 자동 이전 (합격 총점 300 -> 합격 평균 60)

## 시험 설정 (여러 시험 관리)
- 홈 화면 [시험 설정] 버튼: 시험명, 답안지 제목(적용 양식 표시명), **과목 구성(과목 수/이름/약칭/문항 수)**, 선택지 수, 수험번호 자릿수, 문제 유형(A/B)과 유형 간 관계를 설정
- 시험을 여러 개 만들어 전환 가능. **정답/배점/합격 평균/과락 점수/채점 결과가 시험별로 따로 저장**됨 (복제, 삭제 지원)
- 채점 결과가 있는 시험은 구조(문항 수/선택지/수험번호/유형/답안지 양식)를 바꿀 수 없음 (이름/제목/과목 이름·약칭은 가능)
- 답안지 **양식(문항 위치 좌표)** 은 `layouts.py` 의 양식 목록에서 선택. 기본: NIA 자격검정 답안지(100문항 5지선다, 수험번호 9자리, A/B형). 같은 답안지를 쓰는 다른 시험은 설정만으로 가능하고, **답안지 디자인이 다른 시험은 그 양식의 좌표를 `layouts/<이름>.json` 으로 추가**해야 함 (형식은 `layouts.py` 설명 참고)
- **새 시험지 추가 (답안지로 인식)**: 시험 설정 창의 [+ 새 시험지 추가] 에서 빈 답안지 PDF/이미지를 올리면 마킹칸(원)을 찾아 정답 영역/수험번호/문제 유형 칸의 좌표를 자동으로 만들고, 미리보기로 확인한 뒤 새 양식 + 새 시험으로 등록 (양식은 `data/layouts/` 에 저장). 가정: 문항은 왼쪽 블록부터 블록 안에서 위->아래로 번호가 붙고, 수험번호는 위->아래 0~9, 유형 칸은 위(왼쪽)부터 A, B... — 미리보기에서 확인 필요. 과목 구성/유형 간 관계는 알 수 없어 기본값(블록 단위 과목)으로 만들므로 시험 설정에서 수정
- 테스트용 가상 답안지는 기본 시험 구성에서만 사용 가능
- 평균 = 과목 점수의 평균(총점/과목 수). 과목 만점이 서로 다르면 합격 평균을 그에 맞게 설정

## A형 / B형 구성과 정답 연결
- 각 과목(20문항)에서 **1~10번 블록과 11~20번 블록을 맞바꿔** B형을 만듦: A형 1~10번 = B형 11~20번, A형 11~20번 = B형 1~10번 (선지 순서는 동일). 규칙: `form_map.py`
- 한 유형의 정답(정답 답안지/엑셀)만 등록하면 다른 유형 정답은 자동 생성. 둘 다 등록하면 서로 일치하는지 검사해 어긋난 문항을 경고(홈 화면/통계 화면)

## 결과 확인 / 통계 (3번 탭)
- **통계 엑셀 다운로드(차트 포함)**: 통계 화면의 [통계 엑셀 다운로드] — 점수 분포/과목별/유형별의 세로 막대·꺾은선 차트가 엑셀 차트로 들어가며 데이터 시트와 함께 저장. [엑셀 다운로드]는 결과 + 문항별 답안 + 통계 전체
- 개별 결과 표 + 통계: 요약(합격률/과락률/평균/표준편차/KR-20 신뢰도), 점수 분포, 과목별(평균/정답률/난이도/과락), 유형별 비교, 블록 정답률 비교, **문항 분석**(정답률/오답률/선지별 선택 비율/변별도/검토 표시)
- 문항 분석은 A·B 합산 **통합**(A형 번호 기준, 같은 문제끼리 합산) + 유형별로 제공. 유형별 응시자 10명 미만이면 변별도·검토는 보류(참고용)
- 실제 응시자 / 테스트 결과를 구분해서 집계. 엑셀 다운로드에 결과 + 통계 시트 포함

## 항상 켜져 있게 (자동 시작 / 자동 재시작 / 감시)
관리자 PowerShell 에서 한 번: `cd D:\OCR_Score_app ; .\install_service.ps1` (다시 실행해도 안전)
- **OCR_Score_Server**: 부팅 때 자동 시작(SYSTEM), 실행 시간 제한 없음(작업 스케줄러 기본 72시간 제한 해제), `run_server.ps1` 이 서버가 종료되면 5초 뒤 자동 재시작, 작업 자체가 실패해도 1분 뒤 재시작
- **OCR_Score_Watchdog**: 5분마다 `http://127.0.0.1:5000/healthz` 확인 -> 꺼졌거나 응답이 없으면 되살림 (기록: `data\server.log` 의 [감시] 줄)
- 감시는 30초 간격으로 3번 연속 실패했을 때만 조치(대량 채점 중 일시 지연 오판 방지). 채점(이미지 판독)은 전체 잠금 밖에서 하므로 채점 중에도 결과/통계/상태 확인이 막히지 않음(`python test_concurrency.py`로 검증)
- 로그 `data\server.log` 는 20MB 가 넘으면 `server.log.1` 로 보관
- 업데이트 방법: `git pull` -> `Get-NetTCPConnection -LocalPort 5000 -State Listen -ErrorAction SilentlyContinue | % { Stop-Process -Id $_.OwningProcess -Force -ErrorAction SilentlyContinue }` (감독자가 새 코드로 자동 재시작)

## 서버 운영 메모 (nginx / 포트) - 2026-11-16 장애 정리
**장애 내용**: 80번 포트를 Windows 포트 포워딩 규칙(`netsh interface portproxy` 80 -> 127.0.0.1:5000, IP Helper 서비스가 선점)이 쥐고 있어 nginx 가 시작하지 못했고, 그 결과 lms/edu/chat 이 접속 불가였으며 http://lms 요청은 OCR 프로그램으로 전달됨. 규칙을 삭제해 해결.
- 80번 포트에 `netsh interface portproxy` 를 **다시 만들지 말 것** (확인: `netsh interface portproxy show all` 이 비어 있어야 함)
- nginx 는 Windows 서비스 `nginx`(NSSM, 자동 시작)로만 다룬다. 직접 `Start-Process nginx.exe` 로 띄우지 말 것 (Windows 에서는 같은 포트에 nginx 가 두 개 붙을 수 있어 reload 가 어느 쪽에 적용될지 불확실)
- 설정 변경: `cd C:\nginx` -> `.\nginx.exe -t` 로 검사 -> 통과하면 reload. nginx 마스터가 SYSTEM 계정이라 reload 는 관리자 셸에서 직접 못 보내고, 일회성 SYSTEM 작업(`schtasks ... /ru SYSTEM` 으로 `nginx.exe -s reload` 실행 후 삭제)을 쓴다. 검사 실패 시 백업(`conf\nginx.conf.bak_*`)으로 복원
- OCR 연결은 `conf\ocr.conf` (80: 인증서 갱신 경로 + https 이동, 443: 127.0.0.1:5000 프록시). `nginx.conf` 의 http 블록에 `include ocr.conf;` 한 줄로 포함
- 확인 명령: `Get-CimInstance Win32_Process -Filter "Name='nginx.exe'"` 의 부모가 `nssm` 인 마스터/워커만 보여야 함. `netstat -ano | findstr LISTENING | findstr ":80 :443 "` 의 소유 PID 도 그 워커 하나
- OCR 서버 상태: `http://127.0.0.1:5000/healthz` -> `{"status":"ok"}`

## 마킹 판독 규칙
- 빨간색 표시는 검토용으로 보고 답안으로 인식하지 않습니다 (검정/파랑 계열 필기구만 답안). 빨간 표시에 가려진 부분은 판독에서 제외합니다.
- 한 문항에 2개 이상 표시하면(정답이 포함되어도) 이중마킹으로 오답 처리(0점)하며, 판독 화면에 보라색 원(표시한 칸)과 파란 원(정답)으로 보입니다. 엑셀 성적총괄표에 이중마킹/무표기 문항 번호가 표시됩니다.
- 검증: `python test_marks.py`

## 진행 표시 / 인쇄 / 이름
- 답안지 채점은 화면에 진행 창(진행률, 현재 파일)이 뜹니다. (`POST /api/grade/students` + `async=1`, `GET /api/grade/progress/<id>`)
- 결과 확인 탭의 `인쇄 (현재 화면)`은 보고 있는 개별 결과/통계만 인쇄합니다 (A4 가로).
- 이름 칸은 손글씨라 자동 인식이 되지 않아, 답안지의 이름 칸을 사진으로 잘라 결과표에 보여 주고 클릭해서 이름을 입력하면 저장/엑셀에 반영됩니다.
- 엑셀 성적총괄표: 순번은 1부터 연속, 시험명/이름 열 추가, 테스트와 실제가 섞일 때만 구분 열 표시.

## 정답 등록 / 인식 범위
- 홈의 `시험지 새로 설정 저장`: 기존 정답 등록을 모두 지우고 배점/합격 평균/과락/민감도를 새로 저장 (`POST /api/config` `reset:true`). 채점된 결과는 유지.
- 채점 시작 탭: 유형(A/B)별 정답 답안지 칸. 칸과 다른 유형 답안지는 거부. 한쪽만 올리면 다른 쪽은 자동 생성(표시: 자동 생성됨)이고 직접 올리면 교체 + 일치 검사.
- 마킹 인식: 원 전체 비율(민감도 값 이상) 또는 가운데만 칠한 경우(원 가운데 비율이 민감도-0.15, 최소 0.45 이상이고 같은 번호 칸의 빈 칸 기준·같은 줄의 빈 칸보다 충분히 진함)를 마킹으로 본다.
- 검증: `python test_slots.py`, `python test_marks.py`

## 문제 유형(A/B) 자동 확인
- 정답이 2개 이상 등록돼 있으면, 채점할 때 등록된 모든 유형의 정답으로 맞힌 개수를 비교한다. 수험생이 표시한 유형보다 다른 유형이 10문항 이상 더 많이 맞으면 그 유형으로 채점하고 `유형확인`으로 표시(검수필요). 유형 표시를 못 읽은 경우도 더 많이 맞는 유형으로 채점 + 표시.
- 결과 표의 유형 칸에 `유형확인 (표시 A)`가 보이고(마우스를 올리면 설명), 엑셀에 `표시한 유형`/`유형 확인` 열이 들어간다. 검증: `python test_typeinfer.py`
- 유형 간 정답 대조 경고(A/B 정답이 서로 맞지 않음)는 화면에 표시하지 않는다.

## 다시 채점
- 채점할 때 원본 페이지 이미지를 `data/sources`에 보관한다(화면으로 제공하지 않음, 결과를 삭제하면 함께 삭제). 채점 시작 탭의 `전체 다시 채점`(체크한 건이 있으면 `선택한 N장 다시 채점`)은 보관된 원본으로 현재 정답/설정/판독 방식을 적용해 다시 채점하며 번호·파일명·입력한 이름은 유지한다. 원본이 없는 이전 결과는 건너뛴다. (`POST /api/regrade`) 검증: `python test_regrade.py`

## 답안지 수정(교정)
- 채점 시작 탭 목록에서 답안지 앞 체크박스를 선택하고 `선택한 N장 수정(교정)`을 누르면 편집 창이 열린다(여러 장이면 이전/저장 후 다음). 문제 유형, 수험번호, 이름, 문항별 답(1~5/무표기)을 고치면 그 값으로 다시 점수를 계산해 결과/통계/엑셀에 반영한다. 원래 판독값은 보관되어 `교정 취소`로 되돌릴 수 있다. (`POST /api/results/<id>/correct`, `/uncorrect`)
- 교정한 건은 상태에 `교정됨`으로 표시되고(검수필요 해제), `전체 다시 채점`에서 제외되어 교정 내용이 유지된다. 검증: `python test_correct.py`

## 응시자 명단
- 홈의 `응시자 명단 등록`: 첫 줄에 `수험번호`/`이름(성명)` 제목이 있는 엑셀·CSV를 올리면 시험별로 DB(`roster:<시험id>`)에 저장. 수험번호로 이름을 찾아 **엑셀 결과표의 이름 열**에 글자로 넣는다(화면에는 이름 사진 유지, 직접 입력한 이름은 덮어쓰지 않음).
- 판독 못 한 자리(?)는 명단에서 유일하게 맞으면 자동 복구(검수 확인 필요), 여러 명이면 후보 표시. 명단에 없는 수험번호는 `명단에 없는 수험번호`로 표시. 엑셀에 `명단 확인` 열과 `미응시자` 시트 추가. (`/api/roster` GET/POST/DELETE) 검증: `python test_roster.py`

## 사용자 계정 / 권한
- 기본 관리자(최초 설정한 hancom, `data/auth.json`) + 관리자가 화면(`사용자 관리`)에서 추가/삭제하는 사용자(`data/users.json`, 비밀번호는 해시로만 저장).
- 권한: 관리자(전체 + 사용자 관리) / 일반 사용자(채점·교정·조회·엑셀) / 조회 전용(보기·엑셀 다운로드만, 서버가 변경 요청을 403으로 차단). 사용자 삭제·비밀번호 재설정·내 비밀번호 변경 시 해당 계정의 기존 로그인은 무효. 기본 관리자는 삭제 불가. 검증: `python test_users.py`
- 비밀번호를 잊은 경우: 서버에서 `reset_password.bat`(auth.json 삭제) 후 최초 설정 → 기본 관리자만 초기화되고 추가 사용자는 유지.
